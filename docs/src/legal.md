# Legal Architecture & Cleanroom Shield ⚖️

Project Immortal adheres strictly to established legal precedents governing cleanroom reverse engineering, interoperability, and digital game preservation:

## Legal Grounding & Case Law Precedents
- **Sony Computer Entertainment, Inc. v. Connectix Corp.** (203 F.3d 596, 9th Cir. 2000): Established that reverse engineering software to produce a non-infringing, compatible product constitutes protected fair use.
- **Sega Enterprises Ltd. v. Accolade, Inc.** (977 F.2d 1510, 9th Cir. 1992): Disassembly of copyrighted object code is fair use where it is the only way to gain access to functional elements.
- **Computer Associates Int'l, Inc. v. Altai, Inc.** (982 F.2d 693, 2d Cir. 1992): Functional and efficiency elements of software are excluded from copyright protection under the Abstraction-Filtration-Comparison test.

## Inviolable Cleanroom Principles
1. **Bring Your Own Data (BYOD)**: Zero copyrighted game files are hosted in or distributed with this software.
2. **Dirty Room vs. Clean Room Isolation**: Disassembly and packet tracing live strictly in untracked sandboxes. Cleanroom code is authored only from formal markdown specifications.
3. **Typed Obligation Ledgers**: All protocol claims and file structures are substantiated by immutable evidence digests and audited with `agyis verify`.
